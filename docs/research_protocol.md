# Research Protocol

Target >=8,000 permitted texts with three independent annotations each. Define sampling by source, language and domain before collection; record exclusions. Pilot 100–200 items, report sentiment Fleiss kappa and disagreement proportions, revise instructions before full annotation. Calculate kappa before adjudication. Freeze dataset and grouped 70/15/15 splits with seed 42. Compare SVM, fastText, trained-embedding BiLSTM, mBERT, AfroXLMR and few-shot LLM using identical splits. Select hyperparameters with validation only; retain a sealed test set until protocol approval. Use accuracy, fixed three-class macro F1 and language-specific F1 with support, class distributions and bootstrap uncertainty. Run multiple training seeds. Learning curves must use nested training subsets and fixed validation data; never draw from test. Few-shot examples come only from training, with prompt/model version recorded; external uploads require explicit permission. Audit sarcasm, slang, spelling and dialect tags with human review; compare error rates and support without inferring demographic identity. Report limitations, source confounds and uncertainty; never treat synthetic scores as evidence.
