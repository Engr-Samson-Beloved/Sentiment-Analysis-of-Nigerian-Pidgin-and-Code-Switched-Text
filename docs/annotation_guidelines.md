# Annotation Guidelines

Work independently without seeing other labels or model predictions. Positive means expressed approval or favourable affect; negative means disapproval or unfavourable affect; neutral means factual content or no dominant sentiment. For mixed sentiment choose the dominant expressed stance; if balanced use neutral and explain. Sarcasm follows intended sentiment only when context supports it; flag uncertainty in notes. Do not assume slang is negative, correct spelling, translate away nuance or infer sentiment from language identity. Preserve Yoruba diacritics, Hausa letters, emojis and punctuation. Ask a language-qualified adjudicator about ambiguous expressions. Language categories: pidgin = predominantly Nigerian Pidgin without substantial English switching; pidgin_english = substantive Pidgin/English switching; english_yoruba = English/Yoruba switching; english_hausa = English/Hausa switching; english_only = English without substantive switching; other_mixed = remaining mixtures. Borrowings alone need not constitute switching. Record rationale and uncertainty; category definitions can be updated in dataset config before annotation freeze. Three distinct raters are mandatory for both labels. Majority votes are provisional consensus; all disagreements are queued and three-way ties require manual adjudication. Never overwrite original ratings.
